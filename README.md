# Mini Shop

Mini Shop is a simple e-commerce web application developed to demonstrate the fundamentals of online shopping systems using web technologies. The application allows users to browse products, view product information, add items to a shopping cart, and manage their shopping experience through an intuitive user interface.

## Features

* Display a list of available products
* View product details
* Add products to the shopping cart
* Remove products from the shopping cart
* Calculate the total price of selected items
* Responsive design for desktop and mobile devices
* User-friendly shopping experience

## Technologies Used

* **JavaScript** – Handles application logic, user interactions, and dynamic content updates.
* **HTML** – Provides the structure and layout of web pages.
* **CSS** – Styles the user interface and improves visual appearance.
* **Vercel** – Hosts and deploys the application for public access.

## Purpose

The purpose of this project is to practice front-end web development concepts, including building interactive user interfaces, managing application state, and creating a responsive shopping experience using core web technologies.
